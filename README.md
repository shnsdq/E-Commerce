
### **E-Commerce Web Application (MERN Stack)**

**Tech Stack:** React.js, Node.js, Express.js, MongoDB, Stripe API, JWT, Cloudinary, Multer, Tailwind CSS

**Description:**
Built a full-stack eCommerce web application using the MERN stack with secure authentication, dynamic product management, cart functionality, and online payment integration.

**Key Features:**

* **Frontend (React):**
  * Developed a responsive and user-friendly UI using React and Tailwind CSS
  * Implemented product listing, product details, cart, checkout, and order history pages
  * Used React Hooks and Context API for state management
    
* **Authentication & Authorization:**

  * Implemented JWT-based user authentication (login/signup)
  * Role-based access control for Admin and Users
* **Product & Order Management:**

  * Admin dashboard to add, edit, and delete products
  * Image uploads handled using Multer and Cloudinary
  * Users can add items to cart, select quantity/size, and place orders
* **Payment Integration:**

  * Integrated **Stripe payment gateway** for secure online payments
  * Managed payment verification 
* **Backend & Database:**

  * Designed RESTful APIs using Express.js and Node.js
  * MongoDB with Mongoose for managing Users, Products, Orders, and Payments
